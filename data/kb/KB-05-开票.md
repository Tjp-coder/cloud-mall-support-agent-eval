# KB-05 开票模块

> 模块:开票(IV)| 条目区间:IV-101~IV-603 | 状态:v0 初稿,待核对与评审
> 来源口径:基于在职期间的业务理解自行整理编写的模拟文档,数值为自洽设计。

---

## 1. 对象定义

- **月账单**:平台按月汇总客户上月消费生成的费用账单,账单编号格式 `BILL202608XXXX`(BILL+年月+4 位序号),是开票的基础数据来源。
- **发票**:客户对月账单发起开票申请、运营审核通过后开具的票据,分增值税专用发票(专票)与增值税普通发票(普票),发票号格式 `INV20260816XXXX`(INV+年月日+4 位序号)。
- **红字发票**:红冲操作生成的负数发票,发票号格式 `RED20260816XXXX`,用于冲销原发票金额。
- **欠票**:客户退订或降配后实退金额小于已开票金额的差额,形成待冲销的欠票,欠票单号格式 `DEBT20260816XXXX`。
- **开票申请单**:客户发起开票申请的记录,单号格式 `APP20260816XXXX`。
- **示例对象**(供用例引用):账单 `BILL2026080001`、发票 `INV202608160001`、红字发票 `RED202608160001`、欠票单 `DEBT202608160001`、开票申请单 `APP202608160001`。

## 2. 规则条目

### 2.1 开票对象

- IV-101 发票类型:发票分增值税专用发票(专票)与增值税普通发票(普票)两种,专票可抵扣进项税、普票不可抵扣,客户开票时二选一。
- IV-102 开票主体:企业客户开票需填写企业名称(抬头)与纳税人识别号(税号),抬头与税号必须与平台注册信息一致,不一致时申请被拒绝。
- IV-103 个人开票:个人客户仅可开具增值税普通发票,无需填写税号。
- IV-104 税号位数:企业税号支持 15 位(旧纳税人识别号)与 18 位(统一社会信用代码)两种,18 位税号由数字与大写字母组成,校验不通过提示"税号无效"。
- IV-105 单张发票上限:单张发票含税金额上限 100 万元,超过 100 万元系统自动拆分为多张发票,每张金额不超过 100 万元。

### 2.2 开票流程

- IV-201 月账单生成:上月费用次月 1 日生成月账单,账单生成后才可发起开票申请,账单未生成时无开票入口。
- IV-202 申请发起:客户在月账单页面发起开票申请,选择发票类型、填写抬头与税号,提交后生成开票申请单。
- IV-203 审核流程:开票申请提交后进入运营审核,审核通过开具发票,审核不通过退回客户修改后重新提交。
- IV-204 审核时限:运营在 3 个工作日内完成开票审核,第 3 个工作日仍未处理自动转人工督办。
- IV-205 开票完成:审核通过后开具发票,普票默认开具电子发票(即时推送),专票默认开具纸质发票(7 个工作日内寄出,邮费平台承担)。
- IV-206 申请时效:月账单生成后 90 天内可申请开票,超过 90 天系统不允许发起开票申请。

### 2.3 可开票金额

- IV-301 已开票净额:已开票净额 = 累计已开票金额 − 累计已红冲金额,其中已作废发票不计入累计已开票金额。
- IV-302 可开票金额:可开票金额 = 累计月账单金额 − 已开票净额,即客户当前还能申请开具的金额上限。
- IV-303 负值拦截:可开票金额 ≤ 0 时,系统不允许发起新的开票申请并提示"当前无可开票金额"。
- IV-304 申请金额上限:单次开票申请金额不得超过当前可开票金额,超出时拒绝提交并提示当前可开票金额。
- IV-305 红冲恢复额度:红冲完成后红字发票金额计入累计已红冲金额,已开票净额下降、可开票金额上升。

### 2.4 欠票

- IV-401 欠票定义:客户退订或降配后,若该订单已开具的发票金额大于实退金额,差额即欠票,欠票金额 = 发票金额 − 实退金额。
- IV-402 欠票触发:退订或降配退款完成后,系统自动比对订单已开票金额与实退金额,实退金额小于已开票金额时生成欠票单。
- IV-403 欠票拦截:客户存在未处理欠票时,系统拦截其新的开票申请,提示"存在未处理欠票,请先处理欠票"。
- IV-404 欠票处理:欠票通过红冲或作废原发票处理,全部欠票处理完成后解除开票拦截。
- IV-405 无欠票:实退金额 ≥ 已开票金额时不产生欠票,客户可直接发起新开票申请。
- IV-406 多笔欠票:客户存在多笔欠票时,按欠票生成时间先后依次处理,未处理完持续拦截开票。
- IV-407 欠票金额精度:欠票金额精确到分(2 位小数),实退金额与欠票差额之和等于原发票金额。

### 2.5 红冲与作废

- IV-501 红冲定义:红冲 = 作废原发票 + 开具红字发票,适用于已认证或已入账的原发票。
- IV-502 作废定义:作废仅针对未使用、未认证、未入账的原发票,直接作废原票,不生成红字发票。
- IV-503 红冲条件:原发票已被客户认证或已入账时,只能红冲,不可直接作废。
- IV-504 作废条件:原发票未交付、未认证、未入账时,可直接作废,无需开具红字发票。
- IV-505 红冲后开新票:红冲完成后客户可对同一金额重新发起开票申请,开具新发票;红字发票与原发票一一对应。
- IV-506 红字发票金额:红字发票金额等于原发票金额,全额冲销,不支持部分红冲。
- IV-507 作废后重开:作废完成后对应可开票金额恢复,客户可重新申请开票;作废的原发票不可恢复。

### 2.6 历史查询

- IV-601 记录永久保留:开票记录(申请单、发票、红字发票、欠票单)永久保留,不可删除,支持按时间、状态、单号查询。
- IV-602 查询范围:客户可查询本人全部开票记录,含已作废与已红冲的历史发票,历史记录状态清晰标注。
- IV-603 数据一致性:历史开票记录的金额、抬头、税号、状态与开票时点一致,不作后续修改,红冲与作废以新记录体现,不改原记录。

## 3. 状态机

```
开票申请状态:
申请中 → 审核中 → 已开票
           └→ 已驳回 ──重新提交──→ 申请中

发票状态(红冲/作废为终态):
已开票 ──红冲──→ 已红冲(原票作废 + 红字发票已开,终态)
已开票 ──作废──→ 已作废(仅未认证发票,终态)
```

- **申请中**:客户提交开票申请后进入,可撤回;进入审核后转审核中。
- **审核中**:运营审核,通过→已开票,驳回→已驳回。
- **已驳回**:审核不通过,客户修改后重新提交回到申请中。
- **已开票**:审核通过并开具发票;发票后续可被红冲或作废。
- **已红冲**:原发票已作废且红字发票已开,发票侧终态,不可再变更。
- **已作废**:原发票直接作废,发票侧终态,不可恢复。

## 4. 边界与拒答

**能答:** 开票申请流程、发票类型、抬头与税号规则、可开票金额计算、欠票规则、红冲与作废、历史查询。

**不能答(拒答依据):**
- 操作类:帮我开票、作废、红冲、改抬头 → 客服只提供咨询,不执行任何操作。
- 内部类:税控接口细节、开票税盘与加签机制、发票成本构成 → 不对外披露。
- 他域类:账单金额对错(计费问题)、返佣、算力券 → 引导至对应模块(联动见第 5 节)。

**需澄清(模糊问题的土壤):**
- 用户未说明开哪张账单或发票 → 要求提供账单号或发票号。
- "发票开多了"但未说明发票是否已认证 → 需确认走红冲还是作废。
- 抬头或税号不一致 → 引导核对平台注册信息后重新提交。

## 5. 联动规则

- **退订/降配 → 欠票**:包年包月退订或降配后,若实退金额 < 已开票金额,触发欠票(见 IV-401),欠票未处理拦截新开票(见 IV-403)。
- **月账单 → 开票**:月账单是开票的基础数据,月账单次月 1 日生成(见 CT-502),账单生成后才可开票(见 IV-201)。
- **退订 → 返佣冲正**:参与返佣的订单退订后,返佣明细同步冲正(见 RB-306),与开票欠票判断相互独立。
- **与返佣无关**:开票金额针对月账单金额,返佣基数针对返佣规则,二者互不影响;开票与否不改变返佣结算。
