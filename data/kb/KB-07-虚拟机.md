# KB-07 虚拟机模块

> 模块:虚拟机(VM)| 条目区间:VM-101~VM-126 | 状态:v0 初稿,待核对与评审
> 来源口径:基于在职期间的业务理解自行整理编写的模拟文档,数值为自洽设计。
> 说明:VM 与容器"差不多",本文档只写与容器的差异,通用规则引用容器编号(见 KB-01)。

---

## 1. 对象定义

- **虚拟机(VM)**:平台以云主机形式交付的算力商品,与容器共享购买/计费/生命周期规则,仅存储、镜像、快照、登录与规格存在差异。
- **系统盘**:VM 必需的系统磁盘,承载操作系统,创建时选定容量档位。
- **数据盘**:独立于系统盘的数据磁盘,可单独挂载与扩容。
- **镜像**:创建 VM 用的操作系统与应用模板,分官方镜像与自定义镜像。
- **快照**:磁盘数据的时间点备份,用于创建自定义镜像,进而基于镜像恢复数据到新 VM。
- **示例对象**(供用例引用):实例 `VM202608160001`(名称"db-server-01")、系统盘 40G、快照 `SNAP202608160001`、用户 138****8888(企业"XX 科技有限公司")。

## 2. 规则条目

### 2.1 通用规则

- VM-101 通用规则:VM 的付费方式、到期缓冲期、按量停机计费、变配/续费/退订规则与容器一致,见 CT-101~CT-105、CT-201~CT-207。

### 2.2 系统盘与数据盘

- VM-102 系统盘容量:系统盘默认 40G,可选 40/80/160G 三档,创建时选定。
- VM-103 系统盘生命周期:系统盘生命周期跟随 VM,不可单独退订或单独释放。
- VM-104 系统盘不可扩容:系统盘容量创建后固定,不支持后续扩容。
- VM-105 数据盘独立:数据盘独立于系统盘,可单独创建、挂载与卸载。
- VM-106 数据盘扩容:数据盘支持扩容,不支持缩容,扩容即时生效。
- VM-107 数据盘挂载上限:单个 VM 最多挂载 20 块数据盘,超出不可挂载。

### 2.3 镜像

- VM-108 镜像类型:支持公共镜像与私有镜像两类;公共镜像按架构(X86/ARM)提供,实例按所选架构过滤镜像,无匹配时提示暂无数据;私有镜像即自定义镜像(见 VM-109)。
- VM-109 自定义镜像创建:自定义镜像通过对指定磁盘创建快照、再由快照生成镜像;镜像创建期间该 VM 不可变配。
- VM-110 镜像用途:基于自定义镜像创建的新 VM,保留原 VM 的操作系统与应用数据。
- VM-111 镜像删除:自定义镜像支持删除;删除后,已基于该镜像创建的 VM 不受影响。

### 2.4 操作系统与登录

- VM-112 操作系统类型:支持 Linux(CentOS/Ubuntu)与 Windows 两类操作系统。
- VM-113 Windows 远程桌面:Windows 镜像默认开启远程桌面,端口 3389。
- VM-114 VNC 登录:支持 VNC 网页控制台登录,无需公网 IP。
- VM-115 SSH 登录:SSH 登录需先绑定公网 IP,且安全组放行 22 端口。

### 2.5 快照

- VM-116 手动快照:支持手动创建快照,快照为磁盘数据的时间点备份。
- VM-117 快照上限:单个 VM 快照上限 7 个,达到上限需先删除旧快照才能新建。
- VM-118 快照恢复路径:平台不提供就地快照回滚;快照恢复方式为 基于快照创建自定义镜像 → 重新购买创建新 VM,新 VM 的数据与快照时刻一致。
- VM-119 快照状态:快照可在 VM 运行中或已关机状态创建,创建中/异常状态不可创建。
- VM-120 快照与镜像关系:快照是镜像的原料,完整链路为 快照 → 镜像 → 新 VM;快照保留用于后续建镜像,镜像用于创建新 VM。

### 2.6 规格与差异

- VM-121 规格范围:VM 规格为 CPU 1~32 核、内存 1~64G,档位比容器更宽(见 CT-106)。
- VM-122 变配重启:VM 变配 CPU/内存后需重启 VM 才在操作系统内生效;容器变配无此要求(见 CT-205)。
- VM-123 关注点差异:VM 更关注操作系统、系统盘、快照、镜像;容器更关注镜像启动、重启策略、挂载与容器服务运行。

### 2.7 共享规则引用

- VM-124 网络与安全组:VM 的安全组、公网 IP 绑定/解绑、内网互通规则与容器一致,见 CT-303~CT-304、CT-401~CT-403。
- VM-125 计费与账单:VM 的出账周期、月账单、计费分界、欠费处理与容器一致,见 CT-501~CT-504。
- VM-126 到期与数据:VM 的到期提醒、缓冲期提醒、释放后数据不可恢复与容器一致,见 CT-601~CT-604。

## 3. 状态机

VM 基础生命周期与容器一致(见 KB-01 状态机):创建中 → 运行中 → 关机中 → 已关机 →(到期)缓冲期 → 已释放。

VM 特有附加状态:

```
运行中 ──创建快照──→ 快照创建中 ──生成镜像──→ 镜像创建中(期间不可变配)──完成──→ 运行中
已关机 ──创建快照──→ 快照创建中 ──完成──→ 已关机
```

- **快照创建中**:对 VM 创建快照时进入,创建完成后回到原状态(运行中或已关机);创建中/异常状态不可发起。
- **镜像创建中**:从快照生成自定义镜像时进入,期间该 VM 不可变配;创建完成后回到运行中。

## 4. 边界与拒答

**能答:** 系统盘/数据盘规则、镜像与快照、登录方式、操作系统、规格范围;通用规则(付费/变配/续费/退订/计费)见 KB-01 容器。

**不能答(拒答依据):**
- 操作类:帮我创建快照/镜像、变配、登录操作 → 客服只提供咨询,不执行任何操作。
- 内部类:底层调度架构、资源成本构成 → 不对外披露。
- 他域类:告警规则、开票/返佣/算力券问题 → 引导至对应模块(联动见第 5 节)。

**需澄清(模糊问题的土壤):**
- "我的虚拟机"但用户有多个 VM → 要求提供实例 ID 或实例名称。
- 系统盘/数据盘容量不清 → 要求明确容量档位。
- 无法登录 → 要求确认登录方式、是否绑定公网 IP 与安全组放行端口。

## 5. 联动规则

- **关机/删除 → 告警数据不足**:VM 关机或删除后,该 VM 监控指标进入数据不足并单独通知(见 KB-02 告警状态机)。
- **购买/变配/退订 → 订单**:VM 购买、变配、退订均生成订单(见 OD-101)。
- **退订 → 开票/返佣**:VM 退订触发退款,若实退 < 已开票金额产生欠票(见 IV-401);参与返佣的订单退订后返佣冲正(见 RB-306)。
- **变配 → 账单**:VM 变配完成时刻作为新旧规格计费分界(见 CT-503)。
- **快照 → 镜像 → 新购**:快照恢复依赖"快照 → 自定义镜像 → 重新购买创建新 VM"链路,测试重点为快照数据在镜像与新 VM 中的完整性(见 VM-109、VM-118)。
