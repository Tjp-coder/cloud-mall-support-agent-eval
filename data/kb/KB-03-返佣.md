# KB-03 返佣模块

> 模块:返佣(RB)| 条目区间:RB-101~RB-505 | 状态:v0 初稿,待核对与评审
> 来源口径:基于在职期间的业务理解自行整理编写的模拟文档,数值为自洽设计。

---

## 1. 对象定义

- **分销商**:平台合作推广主体,分一级分销商与二级分销商;一级分销商由平台直接结算,二级分销商由一级分销商线下结算。
- **返佣规则**:供应商或自营商家为商品配置的返佣规则,含商品、合同折扣、返佣比例、指定客户;规则编号格式 `RBG202608160001`(RBG+年月日+4 位序号)。
- **返佣账单**:客户下单支付后按命中的分佣规则生成的分佣记录;账单编号格式 `FY202503102323237323`(FY+生成时间 YYYYMMDDHHMMSS+4 位随机)。
- **结算单**:按月汇总一级分销商返佣明细(含冲正)生成的结算凭证;结算单编号格式 `JX202502XXXX`(JX+归属结算周期年月+4 位序号)。
- **示例对象**(供用例引用):返佣规则 `RBG202608160001`(商品"容器 2核4G"、返佣比例 10%、指定客户 138****8888)、返佣明细 `RB202608160001`(订单 ORD202608160001:订单金额 1000.00 元 − 代金券 100.00 元 − 积分 50.00 元 = 返佣基数 850.00 元,返佣金额 85.00 元)、结算单 `JX2026080001`(一级分销商"分销商A"、结算金额 12,850.00 元)。

## 2. 规则条目

### 2.1 角色与对象

- RB-101 分销商层级:分销商分一级与二级;一级分销商为平台直接结算对象,二级分销商由一级分销商线下结算,平台不介入一级与二级之间的资金往来。
- RB-102 商家角色:供应商与自营商家均可配置返佣规则,每条规则需平台审核通过后方可生效。
- RB-103 客户指定:客户需被返佣规则指定后才享受折扣价并计入返佣;未被指定的客户下单不参与返佣。
- RB-104 二级分销商线下结算:二级分销商的返佣由一级分销商线下支付,平台仅展示其返佣明细数据,不生成结算单、不执行资金操作。
- RB-105 一级分销商结算:平台只对一级分销商生成返佣结算单,并在线下汇款完成后记录汇款结果。

### 2.2 基数规则

- RB-201 返佣公式:分佣金额 = 本期返佣基数 × 分佣比例(或按商家设定的固定金额返佣),金额保留 2 位小数四舍五入。
- RB-202 分佣比例取值:返佣比例按"实际折扣区间"阶梯匹配,区间阈值与对应比例由商家配置、平台审核;参考配置:无折扣返佣 30%、9折≤实际折扣<无折扣返佣 25%、8折≤实际折扣<9折返佣 20%、7折≤实际折扣<8折返佣 10%、实际折扣<7折 无返佣;实际折扣 = 订单现金实付金额 ÷ 商品原价。
- RB-203 返佣基数公式:本期返佣基数 = 订单现金实付金额(实付 = 商品原价 × 合同折扣 − 优惠券/代金券/积分/赠送金等抵扣);基数为 0 时不生成分佣账单。
- RB-204 优惠与折扣:合同折扣与活动优惠(预售/首单优惠/限时折扣)并存时择优取低折扣;优惠抵扣顺序为先抵代金券、再抵积分、后抵优惠券/赠送金;实际折扣按最终现金实付计算,并决定命中的分佣比例区间。
- RB-205 积分抵扣:客户使用积分抵扣时,积分抵扣部分不计入返佣基数,从实付金额中扣除。
- RB-206 代金券抵扣:客户使用代金券抵扣时,代金券抵扣部分不计入返佣基数,从实付金额中扣除。
- RB-207 优惠券抵扣:优惠券抵扣视为商家让利,不减少返佣基数。
- RB-208 合同折扣:规则中的合同折扣为客户下单享受的折扣,订单金额为折扣后金额,返佣基数按折扣后实付金额计算。
- RB-209 预售订单:预售订单的定金单与尾款单分别生成分佣账单;按整个订单(定金实付 + 尾款实付)总价计算实际折扣,满足分佣区间才生成返佣账单。
- RB-210 基数下限:返佣基数最小为 0(优惠抵扣合计不超过订单金额);基数为 0 时不生成分佣账单。

### 2.3 流程与明细

- RB-301 返佣流程:返佣流程为 商家配置规则 → 客户下单 → 生成分佣账单 → 生成结算单 → 线下汇款。
- RB-302 账单生成时机:基于订单结算的预付费订单,交易成功即生成分佣账单;基于账单结算的预付费订单,每个自然月 1 日按上月实际消费金额生成分佣账单;后付费订单按量出账后生成分佣账单。
- RB-303 分佣账单字段:返佣账单ID(FY+生成时间YYYYMMDDHHMMSS+4位随机)、采购客户、客户主账号、客户类型、归属一级分销商、归属二级分销商、关联订单ID/售后单ID、计费方式、交易类型、商品总价、定金支付、合同折扣、实际折扣、本期返佣基数、返佣比例、预估返佣金额、归属结算周期。
- RB-304 明细可追溯:分佣账单关联订单号,可反查该订单的金额与优惠抵扣构成。
- RB-305 一单一账单:一笔符合条件的订单商品行生成一条分佣账单,不重复、不拆分。
- RB-306 退款负向分佣:订单退款后,退款单生成负向分佣账单,分佣比例取原订单的分佣比例;按比例返佣时负向金额 = 实退金额 × 原分佣比例,按固定金额返佣时按退款比例退回固定金额。
- RB-307 无理由退款:七天无理由全额退款的订单不产生分佣账单;已生成分佣账单的,通过负向账单冲销。
- RB-308 账单不可改:分佣账单生成后不可人工修改,发生调整时通过负向账单体现。
- RB-309 归属不可变:分佣账单归属的分销商以客户下单时被指定的分销商为准,下单后不可变更。
- RB-310 分佣账单生成逻辑:下单时先判断客户是否命中"指定客户合同折扣"(特定规则),命中则按合同折扣计算金额并按实际折扣取分佣比例;未命中再判断商品是否命中"分销商品范围"(通用规则),命中则按实际折扣取分佣比例;两者均未命中则该 SKU 不参与分佣。
- RB-311 规则优先级:特定规则(指定客户合同折扣)优先级高于通用规则(品类+地域/SPU/SKU 分销范围);范围重叠时按 SKU > SPU > 品类 取值。
- RB-312 结算模式:支持"基于订单结算"(预付费下单即分佣)与"基于账单结算"(预付费按自然月核算消费金额再出分佣账单)两种,由商家为一级分销商配置。

### 2.4 结算单

- RB-401 结算周期:返佣按月结算,次月 5 日生成上月返佣结算单,结算单归属结算周期为对应年月(如 202502)。
- RB-402 结算对象:结算单按一级分销商生成,每月每个一级分销商一张结算单。
- RB-403 结算金额:结算单生成时先记录预估待结算金额(当月该分销商返佣明细含冲正金额之和),核算通过后更新为最终结算金额。
- RB-404 结算单字段:结算单含 分销商ID、分销商名称、归属结算周期、预估待结算金额、最终结算金额、结算状态 6 个字段。
- RB-405 结算单可下钻:结算单关联当月返佣明细列表,可下钻查看每条明细金额。
- RB-406 线下汇款:结算单进入待支付后,由自营商家线下汇款并上传付款凭证确认支付;平台只记录结果,不做在线资金流转。
- RB-407 结算单不可改:已生成结算单金额不可修改,调整通过后续月份的冲正明细体现。
- RB-408 无需返佣:某分销商上一结算周期无返佣账单时,仍生成结算单,默认状态为"无需返佣",不进入核算流程。

### 2.5 变更与冲正

- RB-501 规则变更:返佣规则变更(比例、合同折扣、指定客户)需重新提交平台审核,审核通过后生效。
- RB-502 变更不回溯:返佣规则变更对已生成结算单不回溯,只影响变更生效后的新订单。
- RB-503 冲正月份:退订冲正明细计入退订发生月;若该月结算单已生成,则冲正计入次月结算单。
- RB-504 比例变更拆分:返佣比例变更按生效时间点拆分计算,生效前的订单按旧比例、生效后的订单按新比例。
- RB-505 结算锁定:每月结算单生成后,该月返佣明细锁定,不再生成新明细。

## 3. 状态机

```
结算单状态:
待核算 → 系统核算中 → 待分销商确认及开票 → 待支付 → 已完结
   │          │                   │
   │          └→ 核算结果导入失败 ──重新核算──→ 待核算
   │                                   
   └──────────────── 分销商确认不通过 ──重新核算──→ 待核算

特殊态:无需返佣(上一结算周期无返佣账单时生成,不进入核算流程)
```

- **待核算**:生成结算单后的默认状态;触发条件=次月 5 日按上月明细生成结算单。自营商家操作"核算返佣"后进入系统核算中。
- **系统核算中**:自营商家确认/导入核算结果后的数据处理过程状态;核算成功→待分销商确认及开票,导入失败→核算结果导入失败。
- **核算结果导入失败**:核算结果导入/处理失败状态;自营商家可重新核算,返回待核算。
- **待分销商确认及开票**:核算结果导入/确认成功,待分销商确认核算结果;分销商确认通过→待支付,确认不通过→分销商确认不通过。
- **分销商确认不通过**:分销商确认结算单核算结果有误;自营商家重新核算,返回待核算。
- **待支付**:分销商确认核算结果后的状态;自营商家操作"去支付"(线下汇款并上传凭证)→已完结。
- **已完结**:自营商家上传付款凭证并确认支付后的终态,不再转移。
- **无需返佣**:特殊状态;该分销商上一结算周期无分佣账单,默认生成结算单但不参与核算,无需返佣。

## 4. 边界与拒答

**能答:** 返佣角色与分销商层级、规则配置与审核、实际折扣与分佣比例区间、返佣基数计算、优惠叠加、分佣账单、结算单周期与金额、退款负向分佣、二级分销商线下结算。

**不能答(拒答依据):**
- 操作类:帮我配置返佣规则、修改返佣比例、发起汇款 → 客服只提供咨询,不执行任何操作。
- 内部类:平台与分销商的真实结算价格、其他分销商的返佣数据 → 不对外披露。
- 他域类:订单进度、开票、算力券问题 → 引导至对应模块(联动见第 5 节)。

**需澄清(模糊问题的土壤):**
- "我的返佣"但用户既是商家又是分销商 → 要求明确是查询商家规则还是分销商结算。
- 分销商名称表述模糊("那个分销商")→ 要求提供分销商名称或结算单编号。
- 优惠组合表述不清 → 要求明确使用了代金券、积分、优惠券中的哪几项及金额。

## 5. 联动规则

- **订单 → 明细**:客户下单支付成功后按命中规则生成返佣明细;订单金额构成见 OD-106。
- **退订 → 冲正**:参与返佣的订单退订后生成负向冲正明细(RB-306);容器退订退款规则见 CT-207。
- **返佣 → 开票**:返佣金额不影响客户开票金额,开票金额以客户月账单实付金额为准(见 IV 模块);返佣是平台与分销商之间的资金往来,不计入客户发票。
