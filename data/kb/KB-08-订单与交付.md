# KB-08 订单与交付模块

> 模块:订单与交付(OD)| 条目区间:OD-101~OD-139 | 状态:v0 初稿,待核对与评审
> 来源口径:基于在职期间的业务理解自行整理编写的模拟文档,数值为自洽设计。

---

## 1. 对象定义

- **订单**:用户在商城购买资源产生的记录,分母订单与子订单;母订单按列表展示,一个商品对应一个子订单编号。订单号格式 `D4AUX0E7X`(字母数字混合 8 位),子订单号为母订单号 + `-序号`,如 `D4AUX0E7X-1`。
- **支付记录**:每笔订单对应一条支付记录,记录支付方式、金额、时间与结果(成功/失败/退款);支付方式含 余额支付、在线支付、线下支付线上确认。
- **发货任务**:订单支付/确认后触发资源开通的任务,记录商城调用控制台开通接口的请求、响应与最终结果;任务号格式 `DLV+年月日(8位)+4位序号`,如 `DLV202608160001`。
- **用户**:订单归属主体,以注册手机号(11 位)标识,分个人/企业,企业含税号。
- **示例对象**(供用例引用):订单 `D4AUX0E7X`、子订单 `D4AUX0E7X-1`、支付流水号 `PAY2026081600000001`、发货任务 `DLV202608160001`、用户 138****8888(企业"XX 科技有限公司")。

## 2. 规则条目

### 2.1 订单状态机

- OD-101 状态机主线:订单外部状态主线为 资源分配中 → 待支付 → 资源待开通 → 资源已开通 → 已完成;分支状态含 资源分配失败、已取消、资源开通失败、待确认支付结果、确认未到账,详见第 3 节。
- OD-102 终态不可变:已取消、资源分配失败、资源开通失败(退款完成后)、已完成 为订单终态,进入后不再发生状态转移。
- OD-103 完成条件:资源开通成功后,系统按参数配置更新订单状态为已完成;云资源订单需先达到资源已开通才生成已完成,已完成前客户可发起售后。

### 2.2 支付

- OD-104 支付方式:订单支持余额支付、在线支付、线下支付线上确认三种方式;余额支付从账户余额直接扣减,在线支付走第三方收银台,线下支付线上确认由商家确认到账。
- OD-105 支付后流转:线上/余额支付成功后,订单进入资源待开通,系统推送订单至云控制平台开通资源;线下支付线上确认方式支付后进入待确认支付结果(见 OD-136)。
- OD-106 订单金额构成:订单应付金额 = 资源费 + 附加商品费 + 带宽费 − 优惠;优惠含 合同折扣、营销活动(预售/首单优惠/限时折扣)、优惠券、代金券、积分;包日订单不参与合同折扣与营销活动,可用优惠券/代金券/积分/赠送金抵扣。
- OD-107 余额支付限制:余额支付需账户余额 ≥ 订单应付金额,余额不足时只能选择在线支付或先充值。
- OD-108 支付失败处理:支付失败(余额不足/第三方支付失败)时订单停留在待支付,不进入发货流程,用户可更换支付方式重试。
- OD-109 支付流水号:每笔支付生成唯一支付流水号(格式见第 1 节),支付记录永久保留。
- OD-110 支付超时:待支付订单下单后 24 小时未支付,系统自动关闭订单(进入已关闭)。

### 2.3 审核与确认

- OD-111 人工确认条件:手工趸售/寄售订单需供应商确认订单,确认通过后进入发货流程;云资源订单(直购)由系统自动流转,无需人工确认。
- OD-112 确认环节:手工趸售订单的确认环节为 供应商确认订单 → 供应商确认发货 → 采购商确认收货,各环节状态见第 3 节。
- OD-113 确认时效:供应商确认订单在 2 个工作日内完成,超时自动提醒;确认通过后订单进入发货。
- OD-114 确认不通过:供应商确认订单不通过时,订单关闭并退款(在线支付原路退回,余额支付退回余额)。

### 2.4 资源开通

- OD-115 开通触发:订单支付成功(或线下确认到账)后,系统推送订单至云控制平台开通资源,无需人工干预。
- OD-116 预占与开通链路:提交订单时商城与云控制平台交互下发预占作业(资源占用,有超时 TTL),预占成功才创建订单(分配资源中);支付成功后推送订单开通资源 → 控制台按购买规格创建资源 → 创建完成资源状态回写商城。
- OD-117 开通成功回写:资源开通成功后,控制台回写资源状态,商城订单状态更新为资源已开通并记录实例 ID。
- OD-118 开通失败处理:云控制平台返回开通失败或商城轮询得到失败结果时,订单更新为资源开通失败,并原路退回已支付金额。
- OD-119 开通重试:开通失败自动重试,最多重试 3 次;3 次均失败则订单进入资源开通失败并退款。
- OD-120 开通时效:资源开通在触发后 10 分钟内完成状态回写;超时未回写按开通失败进入重试。
- OD-121 状态一致性:商城订单"资源已开通"必须对应控制台资源状态"创建成功/运行中";订单"已完成"仅在资源已开通后生成,两者不一致视为链路缺陷。
- OD-122 状态一致性定位:商城显示资源已开通但控制台无资源时,依次核查 订单状态与开通任务 → 商城调用开通接口的请求响应 → 控制台资源记录 → K8s/KubeVirt 资源创建,按问题停留层判定为商城业务问题、控制台问题或底层资源问题。

### 2.5 取消与退款

- OD-123 待支付取消:待支付订单用户可自行取消(二次确认),取消后订单进入已取消,不产生费用。
- OD-124 支付后取消:支付成功后不支持直接取消订单,需改走退订流程(见 CT-207 退订规则)。
- OD-125 退款路径:退款原路退回(在线支付)或退回余额(余额支付);用户也可选择将退款转至余额。
- OD-126 退款时效:原路退回 3~7 个工作日到账,退回余额即时到账。
- OD-127 开通失败退款:资源开通失败时订单退款,退款原路退回已支付金额,按量订单开通失败无退款(后付费无预付款)。
- OD-128 取消终态:订单取消成功后进入已取消,已支付订单的实际退款以退款记录为准。

### 2.6 订单查询

- OD-129 查询方式:订单支持按订单号或注册手机号查询;订单号精确匹配,手机号按最近下单时间倒序展示全部订单。
- OD-130 保留期限:订单记录永久保留,已取消、已关闭订单均可查询。
- OD-131 查询范围:订单详情包含订单状态、金额构成、支付方式、发货任务、实例 ID、优惠明细。
- OD-132 查询权限:订单查询仅限订单归属账号;客服代查需用户提供订单号或手机号验证。

### 2.7 订单补充规则(原型核对追加)

- OD-133 母订单与子订单:订单列表按母订单展示;一个商品对应一个子订单编号,同一商品多数量按"商品+数量"拆分多个子订单。
- OD-134 按量订单状态:后付费(按量)订单无待支付状态、不展示订单金额;状态集为 资源分配中/资源分配失败/资源待开通/资源已开通/资源开通失败/已完成;按量订单支付方式默认为余额支付,需先开通余额支付,提交时校验账户可用余额 ≥100 元。
- OD-135 续订订单:订单类型为"续订"的订单状态集为 待支付/资源待开通/资源已开通/资源开通失败;续订前校验资源是否超过服务终止时间,超过则提交失败。
- OD-136 线下支付确认:线下支付线上确认方式支付后,订单进入待确认支付结果;商家确认到账→资源待开通,确认未到账→确认未到账(客户可重新支付)。
- OD-137 试用时长:手工趸售订单含试用时长(默认 30 天),试用到期时间独立于采购时长到期时间。
- OD-138 申请合同:资源已开通/已完成状态的订单可申请合同,生成合同申请单(编号 CA+年月日时分+4 位随机);勾选多个订单合并为一张申请单;已提交过申请(已关联合同申请单)的订单不可重复提交。
- OD-139 是否退订:订单存在关联退订申请单且申请单状态为 待确认申请单/待退款/售后完成/待确认退款结果/确认未到账 时,订单标记"是否退订=是"。

## 3. 状态机

```
订单外部状态(云资源订单):
资源分配中 ──预占成功──→ 待支付 ──支付成功──→ 资源待开通 ──开通成功──→ 资源已开通 ──参数配置──→ 已完成
   │                        │                   │
   └──预占失败──→ 资源分配失败(终态)     ├──线下支付线上确认──→ 待确认支付结果 ──商家确认到账──→ 资源待开通
   │                        │                   │                        └──商家确认未到账──→ 确认未到账(可重新支付)
   │                        └──24小时未支付/手动取消──→ 已取消(终态)
   │                        └──开通失败重试3次仍失败──→ 资源开通失败(终态,原路退款)

手工趸售/寄售订单(供应商确认环节):
待提交 → 待确认(供应商确认订单) → 待发货(供应商确认发货) → 待确认收货(采购商确认收货) → 已完成
   └──确认不通过──→ 已关闭(退款)
```

- **资源分配中**:终端客户提交订单后,系统与云控制平台交互下发预占作业,预占成功且创建订单成功;预占失败→资源分配失败。
- **待支付**:预占作业成功后的状态;支付成功→资源待开通,24 小时未支付或手动取消→已取消。
- **资源待开通**:支付成功(或线下确认到账)后进入,系统推送订单至云控制平台开通资源;开通成功→资源已开通,失败→资源开通失败。
- **资源已开通**:云控制平台返回开通结果;资源开通后按参数配置→已完成。
- **已完成**:订单全流程终态,不再转移。
- **已取消**:超时未支付/手动取消进入;终态。
- **资源分配失败**:预占作业失败进入;终态。
- **资源开通失败**:开通失败且重试 3 次仍失败进入;终态,原路退回已支付金额。
- **待确认支付结果**:线下支付线上确认方式支付后进入;商家确认到账→资源待开通。
- **确认未到账**:商家确认订单未到账进入;客户可重新支付,重新支付后回到待确认支付结果。

## 4. 边界与拒答

**能答:** 订单状态流转(资源分配/待支付/开通/完成)、支付方式与线下支付确认、手工趸售订单的供应商确认环节、资源开通进度、取消与退款规则、续订与按量订单差异、订单查询方式、申请合同、订单与控制台资源状态一致性判定。

**不能答(拒答依据):**
- 操作类:帮我改订单、取消订单、退款、注销账户 → 客服只提供咨询,不执行任何操作。
- 内部类:控制台内部接口实现、K8s/KubeVirt 底层调度细节、资源成本构成 → 不对外披露。
- 他域类:开票/返佣/算力券/容器规格问题 → 引导至对应模块(联动见第 5 节)。

**需澄清(模糊问题的土壤):**
- "我的订单"但用户有多个订单 → 要求提供订单号或手机号。
- "发货了但没收到资源"表述不清 → 要求提供订单号,核查订单状态与控制台资源状态。
- 金额/优惠细节不清 → 要求提供订单号查询订单详情。

## 5. 联动规则

- **订单 → 资源交付**:订单"资源已开通"必须对应控制台资源"创建成功/运行中"(OD-121),不一致按 OD-122 分层定位。
- **订单 → 账单**:订单应付金额构成(OD-106)与月账单费用口径一致,订单支付完成后计入对应账单周期(见 CT-502 月账单)。
- **订单 → 返佣明细**:参与返佣的订单完成后生成返佣明细,订单退订/取消后对应返佣明细冲正(见 RB-306)。
- **订单退订 → 开票欠票**:订单退订按退款系数退回部分金额,若实退金额 < 已开票金额,触发欠票并拦截继续开票(见 IV-401 欠票规则)。
