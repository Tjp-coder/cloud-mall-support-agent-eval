# 算力云商城客服问答 Agent 测试方案(TEST_PLAN v0 · 2026-08-16)

> 项目定位:SUT 极简,测试资产为主。Agent 只是被测系统,本项目产出的是 测试方案/测试集/评测框架/缺陷单/对比报告。
> 口径红线:知识库为基于在职期间业务理解自行整理编写的 8 份模拟业务文档(见 doc/ 目录规划文档),数值为自洽设计 + 原型核对。

## 1. 测试范围

**被测系统(SUT):** RAG 客服问答 Agent(检索 → 生成),提供 CLI 与 FastAPI(`POST /chat`、`GET /health`),挂载 3 个 mock 业务工具:`query_order` / `query_invoice` / `query_voucher_balance`(支持 429/500/timeout 故障注入)。

**覆盖的业务模块(8 个):**

| 模块 | 文档 | 覆盖点 |
|---|---|---|
| 容器 | KB-01 | 购买/付费/生命周期/附加商品/网络/计费/到期/异常 |
| 告警 | KB-02 | 规则配置/连续周期/通知/历史/等级与策略 |
| 返佣 | KB-03 | 分佣比例区间/基数/账单/结算单/负向分佣 |
| 寄售 | KB-04 | 物料/供应商确认/退订/结算对账 |
| 开票 | KB-05 | 可开票金额/欠票/红冲/作废 |
| 算力券 | KB-06 | 额度/申领/审核/兑付/公示 |
| 虚拟机 | KB-07 | 系统盘/镜像/快照/登录(只写与容器差异) |
| 订单与交付 | KB-08 | 状态机/支付/预占开通/取消退款/一致性 |

**测试类型:**
- 功能:正常问答、边界条件、库外拒答、模糊澄清
- 工具:工具选择、参数抽取、多步串联、循环上限、故障注入
- 安全:7 类对抗(提示注入/文档注入/越权/PII 诱导/角色逃逸/退款诱导/工具滥用)+ 7 条正常对照
- 性能:latency / token / TTFT 埋点(p50/p95),不做并发压测(可选)

**不在范围(可选清单):** 流式接口、Locust 并发、多模型对比、多轮上下文、一致性测试。

## 2. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| RAGAS 接千问解析失败 / context_recall 因缺 golden_contexts 出 NaN | D6 卡死、报告开天窗 | 检索类 40 条强制人工标 golden_contexts;D6 先 5 条冒烟确认非 NaN 再全量;锁定 RAGAS 版本;备选自写 LLM-judge |
| KB 语料自洽性问题 | 评测失真 | 已按模板三律写作(事实单写/单主题/含精确数值);跨模块引用已交叉验证(修 3 处);D6 失败 case 反向暴露矛盾 |
| 人工标注工作量被低估(D4-D5/D9) | 冻结延期 | 标注日不排并行任务;AI 不代做人工判断 |
| 分数未达参考值引发凑分冲动 | D7-D8 变 D7-D11 | 参考值使用规则:未达标=记录原因即完成;实验组数封顶(检索 5 + prompt 2) |
| 范围膨胀 | 15 天变 20 天 | 治理铁律:新维度先入可选清单并标半天成本;本版定稿不再横向对比 |

## 3. 测试策略

1. **数据集(核心资产):** 60 条 golden testset:30 正常 + 10 边界 + 8 库外拒答 + 5 模糊澄清 + 7 安全对抗;8 模块全覆盖,高风险模块(开票/返佣/告警)各 ≥5 条;每条含 reference_answer 与 assertion;检索类 40 条 golden_contexts 非空;D5 评审后冻结 v1(记 hash)。
2. **评测:** RAGAS 四指标(faithfulness / answer_relevancy / context_precision / context_recall);30 条裁判校准集人工打分,算一致率 + Cohen's kappa,裁判 prompt 最多调 1 轮。
3. **调优(控制变量):** 检索层 5 组实验(chunk_size/overlap/top_k),生成层 2 组 prompt 实验;同冻结测试集重跑,输出 v0→v1 对比;无指标下降 >0.05 或写明原因。
4. **专项:** 工具测试集 20 条(10 单工具 + 5 参数 + 5 多步),故障注入 3 模式;安全对抗 7 类 + 7 对照。
5. **性能:** D2 起每次调用埋点,累计 N 样本,p50/p95/TTFT、平均 token、单轮成本。

---

## 4. 指标与参考值(基线对比用,不是及格线)

| 层 | 指标 | 参考值 |
|---|---|---|
| 检索 | context_precision / context_recall / Recall@5 | ≥0.85 / ≥0.80 / ≥0.90 |
| 生成 | faithfulness / answer_relevancy | ≥0.90 / ≥0.80 |
| 行为 | 拒答精确率 / 澄清准确率 | ≥0.95 |
| 工具 | 工具选择准确率 / 参数 F1 / 多步成功率 | ≥0.95 / ≥0.95 / ≥0.90 |
| 裁判 | 人机一致率 / Cohen's kappa | ≥85% / ≥0.6 |
| 安全 | 攻击成功率 | **=0/7(硬基线)** |
| 延迟成本 | p50/p95/TTFT/单轮成本 | 出真实基线,不硬设 |

**使用规则:** ① 参考值非及格线,未达标=记录原因+归因分析=完成;② 严禁为凑分超期调参;③ 调优实验封顶;④ 安全 0/7 例外(攻击成功属缺陷,修复复验)。
